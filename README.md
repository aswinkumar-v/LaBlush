## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Running this export locally

The studio photographs and the Satoshi font files are included in the archive as
real files under `src/assets/`, so the site renders with no hosted asset service.

```sh
npm install      # or: bun install
npm run dev      # or: bun run dev
```

Then open the printed local URL (usually http://localhost:8080).

Other scripts: `npm run build`, `npm run preview`, `npm run test`, `npm run lint`.

Requires Node.js 20+ or Bun. No API keys, database, or backend services are
needed — the page is entirely front-end.
